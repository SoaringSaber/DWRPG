# Dandy's World Role-Playing Game
An RPG made by SoaringSaber, inspired by the game *Dandy's World* by BlushCrunch Studios and Quelver.<br>
**Version `0.0.3a` - Alpha Build**

"A nice RPG where all you need to do is *hug everyone like pals, though* it's *harder* than *expected, man*!"
## Disclaimer:
This is an unfinished product, nothing is guaranteed to work perfectly, and some things will break. Please bear with me as I am a solo dev. If you have any suggestions or bug reports, feel free to bring them to my attention, or make a pull request that fixes the issue!

The final game may or may not deal with heavy topics like death, grief, some descriptions of gore, and potentially other disturbing content to some. If you feel uncomfortable with the aforementioned, please don't play. If by popular demand people want to censor that text, it might be implemented. If you're completely fine with the content, please enjoy the game, and THANKS FOR PLAYING!

## How to Play
Currently, there's no real way to "play" the game, it's still very-very-very early in development and will not have much functionality other than backend things.<br>
If you would like to check out the code and tinker around with it, feel free to do so!<br>
Optionally, you can check out what I've done on the frontend so far by starting the game through Launcher.java with the `devTesting` variable inside being set to "false".
